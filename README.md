I've spent the last few years building financial software for Private Equity — cap tables, valuation engines, Excel integrations — and more recently have been deep in applied AI: custom MCP servers, RAG pipelines, AI agents with institutional knowledge, and in-app chatbots wired directly into product workflows.

The two interests have started to converge in interesting ways. Building an MCP server that exposes live PE data to external platforms with OAuth and client-scoped access is a very different problem from building a waterfall calculation engine — but I enjoy both ends of it.

---

### Work that I'm proud of

**DealsPlus Cap Table Engine** — models ownership across complex multi-round structures, tracking share classes, investor stakes, and how dilution plays out as new rounds come in. Built to stay accurate as cap tables get messy in the real world.

**Valuation Engine** — integrated Excel-compatible valuation models directly into the platform, making complex financial modelling feel native to the product rather than bolted on.

**DealsPlus MCP Server** — custom MCP implementation exposing live deal and investor data to external platforms (Claude, etc.) with OAuth, client-scoped access control, and SSE transport. Built so PE analysts can query their own data conversationally without leaving their workflow.

**AI Agent with Institutional Knowledge** — RAG-backed agent trained on platform domain knowledge and client-specific data. Connects into product workflows so it can answer questions about specific deals, structures, and investors in context — not just generic finance answers.

**In-app AI Chatbot** — end-to-end chatbot integration wired into application state and workflows, not just a floating widget. Understands what the user is looking at and can take actions within the product.
